# ARNN Project

Machine learning project (2024-2025) covering a **classification** task and a **regression** task, each in its own Jupyter notebook. The classification notebook works on the Adult (census income) dataset and compares several machine learning models. The project statement is in [`Projet TP 24-25.pdf`](Projet%20TP%2024-25.pdf).

## Repository structure

```
.
├── classification_projet.ipynb   # Classification task
├── regression_projet.ipynb       # Regression task
├── datasets/
│   └── adult/                    # Adult dataset
├── Statistiques images/
│   └── Classification/           # Statistics and plots from the classification task
├── catboost_info/                # Training logs generated by CatBoost
├── Projet TP 24-25.pdf           # Project statement
├── requirements.txt              # Python dependencies
└── README.md
```

## Tech stack

| Library | Purpose |
|---------|---------|
| `pandas`, `numpy` | Data loading and manipulation |
| `matplotlib`, `seaborn` | Visualization and statistics plots |
| `scikit-learn` | Preprocessing, classical models, evaluation |
| `xgboost`, `lightgbm`, `catboost` | Gradient boosting models |
| `tensorflow` | Neural networks |

## Getting started

```bash
git clone https://github.com/sarahmoussaoui/ARNN-Project.git
cd ARNN-Project

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
pip install notebook            # to open the .ipynb files
```

## Usage

Start Jupyter from the project root so the notebooks find the `datasets/` folder:

```bash
jupyter notebook
```

Then open and run the notebooks from top to bottom:

- `classification_projet.ipynb`: data exploration, preprocessing, model training and evaluation on the classification task. The plots are also saved in `Statistiques images/Classification`.
- `regression_projet.ipynb`: the regression task.

## Notes

`catboost_info/` is created automatically when a CatBoost model is trained. It can be deleted safely and added to `.gitignore`.
